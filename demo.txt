### SECTION 3: Incorrect Prediction Deep Dive [~40 seconds]

*Return to Post 4.*

"Now the failure case. The model predicted analysis for this inquiry post about a question about running in a neighborhood. This is the most common error pattern in TakeMeter — technical running vocabulary like 5K. The model learned to associate that vocabulary with analysis regardless of whether the post is making an argument or asking a question. This is a vocabulary proxy problem, not a label boundary problem — and it's directly tied to having only 200 training examples, not enough to separate similar-sounding posts by communicative purpose."

### SECTION 4: Evaluation Report Walkthrough [~60 seconds]

*Switch to your README or evaluation_report.md.*

"Here's a summary of the results. The baseline — Claude Haiku with zero-shot prompting — achieved 0.633 accuracy and 0.61 macro F1. The fine-tuned DistilBERT model achieved 0.333 accuracy. The baseline outperformed fine-tuning in this case.

*Show the confusion matrix.*

The confusion matrix tells the story clearly — the fine-tuned model predicted analysis for 29 of 30 test examples. This is class collapse. Across three training runs with different class distributions, the model collapsed to whichever label held the plurality each time. That pattern strongly suggests 200 examples is insufficient for DistilBERT to learn the semantic boundaries between these labels.

The baseline succeeded where fine-tuning failed because zero-shot prompting gave the model direct access to the decision logic through the system prompt. Fine-tuning on a small imbalanced dataset couldn't replicate that.

The path forward is clear: expand to at least 150 examples per label and revisit the analysis-inquiry boundary with more targeted examples before retraining."

## Recording Tips
- Run inference cells live rather than showing screenshots — it reads more authentically
- Have your posts ready in a list cell so you can run them quickly without typing
- Keep the confidence score visible — if your notebook doesn't show it, add `print(f"Label: {label}, Confidence: {score:.2f}")` to your inference cell
- Aim for ~4 minutes — leaving room for pauses and natural pacing
